# WPL2 Backend

C# backend for the WPL2 team project (PXL Graduaat Programmeren, 2024-25): ASP.NET Core Web API with JWT auth, a WPF admin app and a shared class library with SQL Server data access. Frontend: [wpl2-frontend](https://github.com/SuyenCode/wpl2-frontend).

**Tech:** C#, .NET, ASP.NET Core Web API, WPF, SQL Server, BCrypt, Mailjet.

> Secrets (DB password, JWT key, mail API keys) are replaced with placeholders such as YOUR_DB_PASSWORD.
